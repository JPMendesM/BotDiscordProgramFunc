# BotDiscordProgramFunc

Projeto desenvolvido na disciplina de Programação Funcional utilizando a linguagem Elixir e o framework Nostrum para criação de um bot Discord.

O bot implementa múltiplos comandos utilizando APIs REST distintas, além de persistência de dados em JSON local utilizando GenServer e Supervisor seguindo os conceitos de OTP.

## Estrutura do Repositório

O projeto principal está localizado dentro da pasta:

```text
bot/
```

## Funcionalidades

- Consumo de APIs REST;
- Pattern Matching;
- Persistência JSON;
- GenServer;
- Supervisor OTP;
- Modularização;
- Integração com Discord utilizando Nostrum.

## Tecnologias Utilizadas

- Elixir
- Erlang/OTP
- Nostrum
- HTTPoison
- Jason
